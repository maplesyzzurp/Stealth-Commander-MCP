# Release verification

Keep the PC runtime, local plugin and account connector as distinct versioned components. Record their exact versions and content hashes with the gateway and authorization source commit. Never reuse a historical test report to certify modified code.

Before a source push, run PC unit tests, launcher/installer tests, gateway and authorization tests, and the release contract checks. Regenerate the complete install manifest after source changes; inspect the exact package file list and scan tracked changes for credentials, local paths and generated state.

Before promoting an installed runtime, verify an isolated install and upgrade, configuration preservation, archive integrity, rollback availability and a harmless stdio call. Test task-owned native, browser and PyCharm launch/control/observe/stop workflows serially. Inspect captures and returned cleanup results. Preserve unrelated applications and the active input desktop.

Before a hosted deployment, record the intended signup mode. `PRIVATE_MODE=false` enables normal website registration and email/password sign-in; `PRIVATE_MODE=true` restricts accounts to the configured allowlist. Preserve authorization-store and limiter bindings, authenticated account dashboards, CSRF checks, selected-device consent, single-use ticket verification, and test-only billing in both modes. Run registration/sign-in and account separation checks for the selected mode, plus revoked/expired credentials, ticket replay, alias and tunnel lifecycle checks against the exact deployment candidate. Follow the service migration notes for legacy URL credentials.

Publishing the ChatGPT plugin additionally needs verified publisher identity, a public support contact, approved privacy/terms pages, supported countries, commerce decisions, dedicated reviewer access, a real demo recording, and executed positive/negative review cases. Website registration does not publish that listing. The Windows preview is distributed through the canonical repository's GitHub Releases as a verified npm archive and ZIP with SHA-256 checksums. The npx command uses that explicit public archive URL; there is no npm registry release. Publisher identity is nexusmap.ai; the sole approved plugin icon is assets/ninja-mask.png. `npm run verify:package` enforces the exact icon hash, all light/dark fields, publisher identity, and personal-attribution checks.

A real clean-Windows installation and public-scale recovery/load acceptance are separate from tests run on the developer's configured machine. Record any unverified gate explicitly instead of calling it passed.
