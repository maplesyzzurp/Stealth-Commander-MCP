and account-plugin readback. It does not certify an unrestricted public release.

## Changes reviewed

- Private mode rejects public account registration, including an unregistered
  allowlisted email. Existing approved-account sign-in remains available. The
  regression failed before the guard was added and passed afterward.
- Native observation uses a fresh response from the exact session guardian to
  establish job and window ownership. It supports a launcher that exits after
  handing work to a child process. Cached PNG export checks the current owned
  job and window rather than relying only on launcher ancestry.
- Observer verification supports the installed process-inspection API. Failure
  to inspect the active input desktop remains an error. Observer stop reports
  success only after confirming the worker stopped and its owned job is empty.
- Installer verification covers the complete declared payload and authored skill
  manifest before installation and checks installed hashes afterward. Payload
  traversal and link paths are rejected; failure exercises marketplace rollback.
- Candidate metadata and website copy use the publisher brand consistently,
  remove non-brand attribution from current content, and describe the supported
  behavior without universal compatibility, safety, or frame-rate guarantees.
  The three supplied ninja images retain their original hashes.
