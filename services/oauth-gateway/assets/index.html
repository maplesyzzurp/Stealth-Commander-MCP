## Stealth Commander

Use Stealth Commander for authorized work on the selected Windows PC.

- Start with doctor and inspect the available tool schemas. Check the readiness results for the requested workflow.
- Use run_command for background commands. Use start_native_app, start_browser, or start_pycharm for an owned hidden desktop.
- Confirm the session desktop differs from the active input desktop before GUI actions. Never use the shared mouse, keyboard, global hotkeys, or desktop switching as a fallback.
- Keep the exact returned session path. Inspect its windows and controls before acting, and verify the actual output before reporting success.
- Work within the requested project. Keep credentials, browser profiles, session data, logs, and captures out of published source.
- Stop only the sessions created for the task when finished, unless asked to keep them active. Verify cleanup.

Remote MCP: https://stealthcommander.pages.dev/mcp
Use OAuth and explicitly select a paired PC. The Windows client must be installed and online. Never put account keys or private connection URLs in this file.

Local MCP configuration

For Claude Desktop, Cursor, Windsurf, or Factory. These manual examples require stealth-commander on PATH from a global install of an approved package archive. Source setup registers supported clients with absolute paths instead. No public npm package is available.

{
  "mcpServers": {
    "stealth-commander": {
      "command": "cmd",
      "args": ["/d", "/c", "stealth-commander", "serve"]
    }
  }
}

Claude Code CLI

claude mcp add --transport stdio stealth-commander -- cmd /d /c stealth-commander serve

Codex CLI

codex mcp add stealth-commander -- cmd /d /c stealth-commander serve

First-time installation
Windows x64, Node.js 18+, and 64-bit Python 3.11+ are required. From the extracted client folder:
node ./bin/stealth-commander.js install
node ./bin/stealth-commander.js doctor
Read the readiness results, then run the setup command above. Setup requirements

        
Optional: install with npx

        npx --yes --package=https://github.com/maplesyzzurp/Stealth-Commander-MCP/releases/download/v1.1.3-private.6/stealth-commander-1.1.3-private.6.tgz stealth-commander install --pretty
        
This installs the Windows client without a global npm install. Pairing is separate. The ZIP download above works without npx.
